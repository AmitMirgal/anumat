title: Introduction
description: Anumat reads insurance policy documents and serves approved coverage rules.
---

Anumat takes insurance policy documents and returns structured coverage rules. It does not check individual patients.

The embedded engine (`@anumat/engine`, `anumat-engine`) extracts those rules without Postgres. Pass a database URL when you want a versioned catalog, an approval workflow, and serving of approved rules. Those catalog features throw `database_not_configured` until a URL (or a `db` client in TypeScript) is set.

The HTTP API in `apps/api` is a separate process. It requires `DATABASE_URL`. `@anumat/js` and `anumat-py` call that API.

This repository is the US market. The license for the open core is Apache 2.0. Code in a directory named `ee/` uses a separate license.

JavaScript and Python are both supported. `@anumat/engine` and `anumat-engine` run the engine in your process, with no Anumat server.

## createAnumatClient

`createAnumatClient` takes one inline object. It is not a named export. The table is that object, written so fumadocs-typescript can render it.

<AutoTypeTable

`baseUrl` is the server origin. The client calls that origin plus `/trpc`. `apiKey` is sent as a bearer token. Both are required. The Python client takes the same two values as positional arguments. See the Python API page.

---
title: Quickstart
description: Extract structured rules from a policy PDF, or run a catalog check with Postgres.
---

The embedded engine does not start the Anumat server. A database is not required to extract rules. Catalog, versioning, and approval need Postgres. The HTTP API is a different process and requires `DATABASE_URL`.

<Tabs groupId="lang" persist items={['TypeScript', 'Python']}>
  <Tab value="TypeScript">

Install the package. It requires Node.js 24 or newer. Local disk needs no extra package. For S3, GCS, or Supabase Storage, also install the matching optional SDK.

```bash
npm install @anumat/engine
```

Extract without a database. Store `result.extraction` yourself.

```ts
import { closeContext, createEngine, extract } from '@anumat/engine';
import { readFile } from 'node:fs/promises';

const engine = await createEngine({
  llm: { strong: 'anthropic/claude-sonnet-4-5', cheap: 'anthropic/claude-haiku-4-5' },
});
const result = await extract(engine, {
  pdf: new Uint8Array(await readFile('bariatric-surgery.pdf')),
  payer: 'UnitedHealthcare',
  title: 'Bariatric Surgery',
});
await closeContext(engine);
```

With a database, apply migrations, then register a source and check it. The seed policy below is the public UnitedHealthcare Bariatric Surgery PDF.

```bash
npx anumat migrate --db postgres://USER:PASSWORD@HOST:5432/DATABASE
```

```ts
import { checkSource, closeContext, createEngine, registerPayer, registerSource } from '@anumat/engine';

const engine = await createEngine({
  databaseUrl: 'postgres://USER:PASSWORD@HOST:5432/DATABASE',
});

const payer = await registerPayer(engine, {
  name: 'UnitedHealthcare',
  slug: 'unitedhealthcare',
  market: 'us',
});

const source = await registerSource(engine, {
  payerId: payer.id,
  title: 'Bariatric Surgery',
  sourceUrl:
    'https://www.uhcprovider.com/content/dam/provider/docs/public/policies/comm-medical-drug/bariatric-surgery.pdf',
});

const result = await checkSource(engine, { sourceId: source.id });
await closeContext(engine);
```

`createEngine` returns the engine. `closeContext` disconnects a database client that `createEngine` opened. Catalog methods throw `database_not_configured` when no URL or `db` is set.

  <Tab value="Python">

```bash
pip install anumat-engine
```

Python 3.10 or newer is required. Each wheel contains the binary for one platform.

Extract without a database. Store `result["extraction"]` yourself.

```python
from pathlib import Path
from anumat_engine import create_engine

with create_engine(
    llm={"strong": "anthropic/claude-sonnet-4-5", "cheap": "anthropic/claude-haiku-4-5"},
) as engine:
    result = engine.extract(
        Path("bariatric-surgery.pdf").read_bytes(),
        payer="UnitedHealthcare",
        title="Bariatric Surgery",
    )
```

With a database, apply migrations, then register a source and check it.

```bash
anumat-engine migrate --db postgres://USER:PASSWORD@HOST:5432/DATABASE
```

```python
from anumat_engine import create_engine

with create_engine("postgres://USER:PASSWORD@HOST:5432/DATABASE") as engine:
    payer = engine.register_payer(name="UnitedHealthcare", slug="unitedhealthcare", market="us")
    source = engine.register_source(
        payer_id=payer["id"],
        title="Bariatric Surgery",
        source_url="https://www.uhcprovider.com/content/dam/provider/docs/public/policies/comm-medical-drug/bariatric-surgery.pdf",
    )
    result = engine.check_source(source_id=source["id"])
```

`create_engine` returns after the engine health check succeeds. The `with` block calls `close()`. Catalog methods raise `EngineError` with code `database_not_configured` when no URL is set.
